### A.1 Biggest port breakages, ranked

1. **`GuiGraphics` is gone** → `GuiGraphicsExtractor`; every `render*`/`draw*`/`submit*` method was renamed.
2. **`Screen`/`AbstractWidget`/`Renderable` no longer `render`** — they `extractRenderState`. A widget now
   *records* into a render state instead of drawing immediately.
3. **`net.minecraft.client.gui.render.state.*` → `net.minecraft.client.renderer.state.gui.*`** (whole package).
4. **`pose()` is an `org.joml.Matrix3x2fStack`** (2-D only, `Matrix3x2f`), not a `PoseStack` — unchanged from
   1.21.11, but note all recorded states snapshot `new Matrix3x2f(pose)`.
5. **Text rendering is a two-phase design**: `Font#prepareText(...)` → `Font$PreparedText#visit(GlyphVisitor)`,
   driven by `GuiRenderer.prepareText()`; the old immediate `drawInBatch*` API is gone, as is
   `net.minecraft.client.font.StringRenderOutput`.
6. `GuiSignRenderState`/`GuiSignRenderer` and `GuiGraphicsExtractor`-level sign rendering were **removed**.
7. `AbstractContainerScreen#renderSnapbackItem` and `#clearDraggingState` were **removed**;
   `ClickType` → `ContainerInput`.
8. `Screen#panoramaShouldSpin()` **removed**; `Screen#extractPanorama(...)` retained.
9. `net.minecraft.client.resources.model.Material` **moved** to `...model.sprite.Material`, and
   `getSprite` now takes `...model.sprite.SpriteId`.
10. `net.minecraft.client.gui.layouts.LayoutElement` and `net.minecraft.client.gui.navigation.*` are
    **unchanged** — these are safe.
